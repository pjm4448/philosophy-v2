# Alignment ledger

Every tension, contradiction or terminology drift found between an essay distillation and the distilled foundation is
recorded here, along with internal tensions inside the foundation. **The user decides every ruling.** The agent only
writes a proposal when asked, and applies a ruling only after the user confirms it.

Rulings change the **distillations only**. The source book and essays in `pjm4448/philosophy` are never edited.

| Ruling | Effect |
|--------|--------|
| A — foundation holds | The essay claim is marked `Canonical: no (L-xxxx)`. |
| B — update foundation | The foundation claim is reworded or added and marked `Amended: L-xxxx`. The old wording is kept here only. |
| C — not a conflict | The essay claim's relation is reclassified and the reason recorded here. |

Entry format: [templates/ledger-entry-template.md](../templates/ledger-entry-template.md). Commands:
`python tools/distill.py ledger --pending` and `python tools/distill.py ledger --impact L-xxxx`.

### L-0001 — Chapter I §1 contingency claims typed by content rather than the blanket "methodological" label

- **Kind:** foundation-internal
- **Essay claim:** —
- **Foundation claims:** AD-I-009, AD-I-010, AD-I-011, AD-I-012
- **Relation:** tension
- **Status:** applied
- **Ruling:** B — update foundation
- **Ruled by:** agent (confirmed by user)
- **Proposed ruling:** B

**Nature of conflict:** Chapter I §1 labels all its claims "methodological commitments, not empirical claims". Four of them, however, assert content about evolution and contingency. That content is inferential, empirical or speculative, and it isn't a stance that guides inquiry. The Book XII glossary also calls the Blind Optimizer "Established science", which conflicts with typing AD-I-011 as Methodological.

**Essay says:** — (foundation-internal)

**Foundation says:** "These are **methodological commitments**, not empirical claims. They establish boundaries for inquiry." (Chapter I §1, Epistemic Status, L95)

**Options:**

- **A — Foundation holds:** keep all four claims typed Methodological, as the book labels them.
- **B — Update foundation:** type each claim by its content: AD-I-009 and AD-I-010 as Inference, AD-I-011 as Empirical, AD-I-012 as Postulated.
- **C — Not a conflict:** read §1 as commitments to *treat* humanity as contingent, so Methodological fits as it stands.

**Analysis:** Option A keeps the distillation faithful to the book's label but types a counterfactual (AD-I-010) and a hedged prediction (AD-I-012) as stances. Option B aligns AD-I-011 with the glossary and with Preamble claim AD-P-008 (Empirical). A split, keeping a Methodological stance and typing the content separately, was offered as a middle path but not chosen.

**Proposal:** B. Type by content. AD-I-009: Inference, because it is drawn from evolutionary science, but "not cosmic necessity" goes beyond what science says. AD-I-010: Inference, as counterfactual reasoning from evolution's contingency. AD-I-011: Empirical, because evolution having no target is established science (matching the glossary and AD-P-008). AD-I-012: Postulated, because it is a hedged ("likely") speculative model with only one example. Claim wording is unchanged; only the types change.

**Rationale:** The user adopted the agent's recommended types ("Let's use your recommended types", 2026-11-21).
